💊제형의 비밀: 아세트아미노펜 속효정과 서방정의 물리화학적 차이

1번 파트에서 고체 알약이 물에 녹고 농도 차이로 퍼져나가는 **기본원리**를 다뤘다면, 이 문서는 그 원리로
**"약을 언제, 얼마나 빨리 내보낼지" 설계하는 기술**로 확장한다. 같은 아세트아미노펜이라도 알약을 어떤 구조로 만들었느냐에 따라 효과가 나타나는 속도와 지속 시간이 달라진다. 이 문서는 일반 속효정(타이레놀정 500mg)과 서방정(타이레놀8시간이알서방정 650mg)이 **어떤 코딩·내부 구조 차이로 방출 속도를 조절하는지** 논문과 공식 자료를 근거로 분석한다.

**아세트아미노펜은 어떤 물질인가: 제형 설계의 출발점**
제형을 설계하려면 먼저 약물 자체의 성질을 알아야 한다.
·**생물약제학 분류(BCS)**: 아세트아미노펜은 [이후 수정]으로 분류되며
·**의미**: 원래 잘 녹고 잘 흡수되는 약이므로, 속효정은 "빨리 부서지게만" 하면 충분하다. 반대로 서방정은 이렇게 잘 녹는 약을 억지로 천천히 녹게 만드는 물리적 장치가 필요하다.
