# team7







## team07 협업 규칙 

###1. 1인 1파일 & 담당 파일 
- 충돌을 방지하기 위해각 팀원은 본인이 담당한 '.md' 파일만을 수정합니다

###2. 메인 브랜치 Direct Commit 금지
-'main' 브랜치에 직접 글을 작성하거나 수정하지 않습니다.
-반드시 개인 작업용 브랜치를 생성하여 작업합니다.

###3. 커밋 메시지 컨벤션
-변경 사항을 기록할 때 말머리를 붙여 명확하게 작성합니다
-'Add: [내용]'- 새로운 내용이나 문서 작성 시 (예: 'Add: 아세트아미노펜 간대사 기전 작성')
-'Fix: [내용]'- 오탈자 수정, 이미지 추가/ 교체 시 (예: 'Fix: 1장 이미지 태그 경로 및 제목 수정)
-'Docs: [내용]'- 양식이나 서식 수정 시

###4. PR(Pull Request) 및 검토 프로세스
- 본인 브랜치에서 작성이 완료되면 'main' 브랜치로 **Pull Request**를 생성합니다.
- **최소 2명 이상의 팀원이 작성 내용을 확인하고 승인** 또는 긍정 댓글을 남기신 후 'Merge' 진행하겠습니다

###5. 본문 작성 필수 조건
위의 사항은 교수님의 채점과 관련된걸로 지정하겠습니다
- 본인 분량의 '.md' 파일당 **글자 수 1000자 이상** 작성하셔야 합니다
- **관련 이미지/ 도식 1개 이상** 마크다운 이미지 태그로 포함 ( '![설명](이미지주소)')
