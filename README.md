# 4. 간 대사와 효소 작용 경로

> 이 문서는 학습용 자료이며, 실제 복용은 의사·약사의 안내와 제품 설명서를 따르세요.

## 들어가며
아세트아미노펜은 먹고 나면 소장에서 빠르게 흡수되어 혈액을 타고 온몸으로 퍼지고, 그중 대부분은 **간(liver)**에서 처리됩니다. 소장에서 흡수된 혈액은 곧바로 온몸으로 가지 않고 먼저 **문맥(portal vein)**을 통해 간으로 모이기 때문에, 먹은 약은 몸 전체를 돌기 전에 간을 한 번 지나게 됩니다. 이때 일부가 미리 대사되는 현상을 **초회 통과 효과(first-pass effect)**라고 합니다.

우리 몸은 약물처럼 몸 밖에서 들어온 물질을 "이물질(xenobiotic)"로 인식합니다. 그래서 이물질을 **물에 잘 녹는 형태로 바꿔서 소변이나 담즙으로 내보내는** 작업을 하는데, 이것을 **약물 대사**라고 합니다. 지용성(기름에 잘 녹는) 물질은 콩팥에서 걸러져도 다시 몸속으로 흡수되기 쉬워서, 몸 밖으로 잘 나가려면 수용성(물에 잘 녹는) 형태로 바뀌어야 하기 때문입니다.

간은 이 대사 작업을 담당하는 효소가 가장 많이 모여 있는 장기라서 흔히 "몸의 화학 공장"이라고 불립니다. 이 문서에서는 아세트아미노펜이 간에서 어떤 효소를 만나 어떤 물질로 바뀌고, 그 부산물이 어떻게 처리되는지를 화학적 관점에서 차근차근 정리합니다.
