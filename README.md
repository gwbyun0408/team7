## 1. 프로스타글란딘이란?

프로스타글란딘(Prostaglandin, PG)은 우리 몸의 거의 모든 조직에서 만들어지는 지질 계열의 신호 물질입니다. 통증, 발열, 염증 반응에 핵심적으로 관여하며, 혈관 확장, 위 점막 보호, 혈소판 응집 조절 같은 정상적인 생리 기능에도 쓰입니다.

프로스타글란딘은 다음과 같은 순서로 만들어집니다.

1. 세포막의 인지질에서 효소(포스포리파아제 A2)가 **아라키돈산(arachidonic acid)** 을 떼어냅니다.
2. **COX(사이클로옥시게나아제, cyclooxygenase)** 효소가 아라키돈산을 **PGH2** 로 바꿉니다.
3. PGH2는 조직마다 다른 합성 효소에 의해 PGE2, PGI2, TXA2 등 여러 종류의 프로스타글란딘으로 전환됩니다.

즉, **COX는 프로스타글란딘 생산 라인의 핵심 관문**입니다. 진통해열제 대부분이 COX를 표적으로 삼는 이유가 여기에 있습니다.
